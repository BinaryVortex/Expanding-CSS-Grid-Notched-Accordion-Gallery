# Expanding CSS Grid Notched Accordion Gallery

A clean, interactive image gallery built with **HTML and CSS**, featuring an expanding CSS Grid accordion layout and a distinctive **notched-card design**.

The gallery uses modern CSS techniques to create a polished interaction without relying on JavaScript or external frameworks.

## ✨ Features

- 🎨 **Notched Accordion Design** — Unique angled/notched panel edges for a modern visual style.
- 📐 **CSS Grid Layout** — Uses CSS Grid to create overlapping gallery panels and control their expansion.
- 🖱️ **Hover-Based Interaction** — Panels expand smoothly when the user hovers over them.
- 🔢 **Automatic Image Counters** — CSS counters provide visual numbering for the gallery items.
- ⚡ **Pure HTML & CSS** — No JavaScript, frameworks, build tools, or dependencies required.
- 🎞️ **Smooth Transitions** — Subtle animations make the panel expansion feel natural.
- 📱 **Responsive-Friendly Structure** — The layout can be adapted for different screen sizes with CSS media queries.
- 🧩 **Easy to Customize** — Replace the images, sizing, colors, and grid settings to create your own variation.

## 🎨 How It Works

The gallery is built around a CSS Grid where the image panels overlap across grid columns. Each panel is assigned a grid position, allowing the cards to visually stack together while still behaving as individual interactive elements.

On hover, the active panel changes its grid sizing so that it occupies more horizontal space. CSS transitions animate this change, producing the expanding accordion effect.

The notched appearance is created through modern CSS corner and border-radius techniques, giving the gallery its distinctive shape.

## 🔧 Customization

You can easily adapt the gallery to your own project.

### Change the images

Update the image/background-image values in `index.html` or `style.css`, depending on how the gallery items are configured.

### Change the number of panels

Add or remove gallery items and update the corresponding CSS Grid placement rules.

### Change the animation

Modify the transition duration and easing in `style.css`:

```css
transition: all 300ms ease-in-out;
```

### Change the visual style

Experiment with:

- Border thickness
- Border radius
- Notch size
- Image sizing
- Grid column spans
- Hover behavior
- Panel spacing
- Typography
